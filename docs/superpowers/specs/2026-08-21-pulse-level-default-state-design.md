# 脉冲电平与默认状态设计

## 目标

将难以理解的“正逻辑 / 反向逻辑”改为独立的“脉冲电平”和“默认状态”选择，并正确处理采集边界处与默认电平相连的首尾不完整脉冲。

## 界面

工具栏提供三个按钮组：

- 脉冲电平：`高电平脉冲`、`低电平脉冲`。
- 默认状态：`默认低电平`、`默认高电平`。
- 计频方式：`按上升沿`、`按下降沿`。

导入具有原始跳变数据的文件时，默认状态由首个电平自动选择：首条为 `0` 选择默认低电平，首条为 `1` 选择默认高电平。脉冲电平默认选择高电平脉冲。PWM 测量直通数据没有原始边沿，三个与边沿解释有关的按钮保持不可用。

## 波形解释

脉冲电平指定用于频率分析的逻辑高脉冲：选择低电平脉冲时，内部仅为计算目的将 0/1 对调，时间戳不变。默认状态保存采集开始和结束时信号静止的电平，用于判断边界脉冲是否与记录外的静止段相连。

如果首个或最后一个待分析脉冲与默认状态相连，则其周期的另一半不可观测。该边界脉冲固定使用 `period = 2 × width`、`dutyCycle = 0.5` 和 `freq = 1 / period`。中间完整脉冲继续使用相邻同向边沿的真实间隔。

例如 `lyb.vcd` 初始和最终均为物理高电平。选择“低电平脉冲 + 默认高电平”后，最后一段 `0 → 1` 是与结束后默认高电平相连的末脉冲，固定按 50% 计算，而不使用前一周期的边沿间隔。

## 状态与兼容性

用 `pulseLevel` 取代 `logicPolarity`，并新增 `defaultLevel`。文件加载保留物理跳变；分析时按脉冲电平映射为逻辑跳变。切换任一解释设置时，重新生成边沿、频率点和脉冲统计，并清除光标、框选和分段结果。

现有高电平脉冲、默认低电平的正常方波保持原有结果；VCD、TXT、SR、Saleae 的原始边沿格式均适用。版本从 `3.0.0` 更新为 `3.1.0`。

## 验证

- 单元测试覆盖高/低电平脉冲、默认高/低状态的四种组合。
- `lyb.vcd` 的最后 `0 → 1` 低脉冲在“低电平脉冲 + 默认高电平”下输出 50% 占空比的尾点。
- 运行 `npm test` 与 `npm run build`。
