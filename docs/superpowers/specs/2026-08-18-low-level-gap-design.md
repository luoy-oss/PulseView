# 低电平间隔测试功能设计

## 目标

在现有单路频率分析页面新增“低电平间隔（测试）”测量，用于识别相邻脉冲之间是否存在额外的低电平停顿，并量化该停顿时间。

## 使用前提

该测量仅适用于稳定的 50% 占空比方波：每个周期必须恰好包含一个完整高电平脉冲，且高电平脉宽等于无额外间隔时的低电平时长。任何占空比偏离、双脉冲、缺失边沿或不完整起始脉冲都会使推导失去物理意义，因此页面将其明确标注为“测试”功能和硬性要求。

## 推导

对第 n 个完整脉冲：

- `W[n] = fall[n] - rise[n]`，即高电平脉宽。
- `T[n] = fall[n] - fall[n-1]`，即相邻下降沿周期。
- 在 50% 占空比基准下，无额外停顿时周期为 `2 × W[n]`。
- 额外低电平间隔为 `G[n] = T[n] - 2 × W[n]`。

`G = 0` 表示连续 50% 方波；`G > 0` 表示相邻脉冲之间存在额外低电平间隔；`G < 0` 表示高电平宽度超过 50% 基准，原始值仍保留。

## 页面与数据流

顶部测量模式组新增“低电平间隔（测试）”按钮。悬停提示会写明公式和严格的 50% 占空比要求。选择此模式后，重用已有跳变数据重算点列；首个脉冲没有前一下降沿，不输出点。图表纵轴和悬浮提示改为“低电平间隔”，单位按现有时间格式化函数显示。导出 CSV 使用 `time_s,low_level_gap_s` 表头。

所有原始 `G` 样本进入图表，包括负值。可选“50% 容差”以百分点为单位；启用时，满足 `|占空比 - 50%| <= 容差` 的样本被归零，其他正值和负值保留。该功能不改变既有脉冲宽度、上升沿周期、下降沿周期及占空比修正的计算口径。

## 验证

为纯计算函数添加覆盖：连续 50% 方波得到零间隔；插入额外低电平时间得到精确正间隔；高占空比得到保留的负推导值；启用容差后仅将范围内误差归零。再运行 TypeScript 构建，并检查版本号、界面文本及导出表头。
